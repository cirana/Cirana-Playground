# Keyboard shortcuts

Global shortcuts work in every application while CIRANA runs. They act on the window that has the keyboard focus. Turn them on or off, or change any of them, in **Settings → Keyboard and focus → Edit shortcuts…** The editor refuses combinations that Windows or most applications already use.

| Action | Default |
|---|---|
| Focus the window on the left | `Ctrl+Alt+Left` |
| Focus the window on the right | `Ctrl+Alt+Right` |
| Focus the window above | `Ctrl+Alt+Up` |
| Focus the window below | `Ctrl+Alt+Down` |
| Move the window left (or to the monitor on the left) | `Ctrl+Alt+Shift+Left` |
| Move the window right (or to the monitor on the right) | `Ctrl+Alt+Shift+Right` |
| Move the window up (or to the monitor above) | `Ctrl+Alt+Shift+Up` |
| Move the window down (or to the monitor below) | `Ctrl+Alt+Shift+Down` |
| Make the tile wider | `Ctrl+Alt+Win+Right` |
| Make the tile narrower | `Ctrl+Alt+Win+Left` |
| Make the tile taller | `Ctrl+Alt+Win+Down` |
| Make the tile lower | `Ctrl+Alt+Win+Up` |
| Monocle: the window fills the screen / back to the layout | `Ctrl+Alt+Enter` |
| Float the window / tile it again | `Ctrl+Alt+Space` |
| Take the window out of its stack | `Ctrl+Alt+Backspace` |
| Show the next window of the stack | `Ctrl+Alt+PageDown` |
| Show the previous window of the stack | `Ctrl+Alt+PageUp` |
| Move the window to the next workspace | `Ctrl+Alt+Shift+PageDown` |
| Move the window to the previous workspace | `Ctrl+Alt+Shift+PageUp` |

## Not assigned by default

Assign these in the shortcut editor if you want them:

- Stack the window with the tile on the left
- Stack the window with the tile on the right
- Stack the window with the tile above
- Stack the window with the tile below
- Activate the next workspace
- Activate the previous workspace

## Inside the CIRANA window

| Action | Shortcut |
|---|---|
| Search and launch applications, categories and workspaces | `Ctrl+K` |
| Collapse / expand the sidebar | `Ctrl+B` |
| Jump to Home, Applications, Workspaces, Windows, Favorites, Settings | `Ctrl+1` … `Ctrl+6` |

## Note for AltGr keyboards

On keyboards with an AltGr key (for example Turkish Q or German), `Ctrl+Alt+<letter>` is AltGr+letter and types characters such as `@` or `€`. The defaults therefore use arrows, Enter, Space, Backspace and Page keys only, and the editor warns before you pick a letter, digit or punctuation key with Ctrl+Alt.
